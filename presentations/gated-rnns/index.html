03 / EXPLANATION & ANALOGY

An input xₜ is a vector at position t. A recurrent neural network (RNN) updates a hidden state hₜ from the current input and previous state. The same learned weights are used at every position; the state values change. A task head can read every state (tagging), the last state (classification), or a causal prefix (next-token prediction).

Think of passing a small notebook along a line. Each person reads new evidence and rewrites the summary. The notebook has fixed capacity; it is neither the original transcript nor the learned rule for writing.

The difficulty is selective memory: useful old information and irrelevant new information share the update. Training also needs a correction from a late error to reach the early operations that caused it.

04 / GIVE THE IDEA A RULE
hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
ŷₜ = head(hₜ)

For column vectors: xₜ ∈ ℝᵈ, hₜ ∈ ℝᴴ, Wₓ ∈ ℝᴴˣᵈ, Wₕ ∈ ℝᴴˣᴴ and b ∈ ℝᴴ. Here tanh acts on each coordinate and maps real numbers into (−1, 1). h₀ is the initial state.

Go deeper · Encoding, shared weights & targets

A word ID is a category label, not a meaningful scalar magnitude. A vocabulary of three words could use one-hot inputs [1, 0, 0], [0, 1, 0], [0, 0, 1]; an embedding layer maps IDs to learned vectors. The scalar inputs below deliberately isolate arithmetic.

Unrolling draws repeated uses of one cell, not independently parameterized layers. For a single recurrent layer with one bias, P = H(d + H + 1); making the sequence longer adds computation, not parameters.

For next-token training, [dog, bites] has targets [bites, person]. The target at a position must not also be supplied as future input to that prediction. Backpropagation through time sends derivatives backward during training; it does not give a forward RNN access to future inputs at inference.

03 / EXPLANATION & ANALOGY

A long short-term memory (LSTM) cell carries two vectors: the cell state cₜ for stored content and the hidden state hₜ for exposed output. A forget gate fₜ scales old memory, an input gate iₜ controls new writing, and an output gate oₜ controls what is exposed. The signed candidate gₜ proposes new content.

Imagine a notebook with three controls: retain part of the old notes, write selected new notes, and open a viewing window onto the page. Closing the window does not erase the notebook. The analogy describes the operations; the model learns continuous, coordinate-wise gates.

A gate is a vector of numbers between 0 and 1, usually produced by a sigmoid. It is not a human rule such as “forget every noun”. Every gate is computed from the current input and previous hidden state using learned weights.

04 / GIVE THE IDEA A RULE
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ gₜ
hₜ = oₜ ⊙ tanh(cₜ)

⊙ means element-by-element multiplication. All four gate/candidate vectors and both state vectors have H coordinates. f = 1 retains; f = 0 removes the old contribution. i controls writing independently; f + i need not equal 1.

Go deeper · All equations, shapes & a worked coordinate
aₜ = [hₜ₋₁ ; xₜ]
fₜ = σ(Wf aₜ + bf) · iₜ = σ(Wi aₜ + bi)
oₜ = σ(Wo aₜ + bo) · gₜ = tanh(Wg aₜ + bg)

Semicolons inside brackets mean concatenation; dots between equations separate formulas, not multiplication. σ(v) = 1/(1 + exp(−v)). Each W has shape H × (H + d); each bias has H values. Sigmoid produces values strictly between 0 and 1 for finite inputs; sliders include the useful idealized limits.

For cₜ₋₁ = 0.8, f = 0.75, i = 0.5 and g = 0.4, cₜ = 0.6 + 0.2 = 0.8. With o = 0.6, hₜ = 0.6 tanh(0.8) ≈ 0.398. With o = 0, hₜ = 0 while cₜ remains 0.8. The hidden value is neither a class probability nor a stored token.

The cell state is not forced into [−1, 1]; additions can accumulate. The standard hidden state is bounded by its tanh and output gate. This worksheet uses the modern forget-gate form, no peephole connections and no projection. For one bias per affine transform, P = 4H(d + H + 1), excluding a task head.

03 / EXPLANATION & ANALOGY

Training uses backpropagation through time: the chain rule sends credit through repeated state updates. Multiplying many small local derivatives can make an early contribution difficult to learn; large factors can instead lead to exploding gradients.

Think of passing a correction through many volume knobs. If every knob turns the message down, the first person barely hears it. The additive LSTM cell route supplies knobs that can be learned near 1, without forcing the old cell content through a new tanh at every link on that route.

Holding gates fixed, the direct edge from cₜ₋₁ to cₜ has multiplier fₜ. A forget gate near 1 can preserve this path. This is a useful mechanism, not proof that the full network has no vanishing gradients.

04 / GIVE THE IDEA A RULE
direct cell-state path: ∏ₖ₌₁ᴸ fₖ
constant f: fᴸ   ·   linear RNN comparison: 0.8ᴸ

For vectors, each direct edge has diagonal Jacobian diag(fₜ). Here L is the number of recurrent links. The displayed product holds gate values fixed and isolates the direct route; total derivatives also include routes through h and the gate computations.

Go deeper · Tanh derivatives, half-life & practical limits

For a scalar vanilla RNN hₜ = tanh(w hₜ₋₁ + xₜ), ∂hₜ/∂hₜ₋₁ = w(1 − hₜ²). Even a weight above 1 may be paired with a small tanh derivative. The interactive comparison removes tanh from its RNN baseline so the two products can be inspected exactly.

With no writes and f = 0.95, an initial cell value retains a fraction 0.95ᴸ. Its half-life is log(0.5)/log(0.95) ≈ 13.5 steps; at f = 0.99 it is about 69 steps. Gate choices and useful timescales depend on the data.

The derivative from cₜ to exposed hₜ also contains oₜ(1 − tanh²(cₜ)). Saturation or a closed output gate can weaken that route even when the cell path preserves information. Gates also depend on prior hidden states. Therefore fᴸ is not the complete gradient of a loss or a parameter.

Gradient clipping limits large accumulated parameter gradients; it does not reconstruct a vanished signal. Truncated backpropagation limits how far training credit travels, even if hidden states are carried farther. LSTM does not remove finite memory, optimization difficulty or sequential computation.

03 / EXPLANATION & ANALOGY

A gated recurrent unit (GRU) combines memory and output into one hidden state. Its reset gate rₜ controls how previous state participates in the candidate. Its update gate zₜ mixes the previous state with that candidate.

Keep one notebook and draft a replacement paragraph on scrap paper. Reset decides how much old context the draft uses. Update decides how much of the old page survives when the draft is merged. Discarding old context from the draft does not force you to discard the old page.

Our convention: z is the fraction of old state retained. Thus z near 1 means “keep”, and z near 0 means “replace with the candidate”. Check the equation in any other reference before interpreting its gate labels.

04 / GIVE THE IDEA A RULE
h̃ₜ = tanh(Wₓxₜ + Wₕ(rₜ ⊙ hₜ₋₁) + b)
hₜ = zₜ ⊙ hₜ₋₁ + (1 − zₜ) ⊙ h̃ₜ

The reset-before-matrix variant is shown. The blend is coordinate-wise: each coordinate has its own r and z. There is no separate output gate or cell-state vector in this GRU.

Go deeper · Learned gates, variants & cost
rₜ = σ(Wr [hₜ₋₁ ; xₜ] + br)
zₜ = σ(Wz [hₜ₋₁ ; xₜ] + bz)

With x = 0.2, old h = 0.8, r = 0.5, weights 1 and bias 0, the candidate is tanh(0.6) ≈ 0.537. At z = 0.75, hₜ = 0.75 × 0.8 + 0.25 × 0.537 ≈ 0.734. At r = 0, the candidate is tanh(0.2), but z = 1 still retains old h = 0.8.

Some references write (1 − z)hₜ₋₁ + z h̃ₜ, so their z means “write”. Some libraries use reset-after-projection, r ⊙ (Wₕh + bₕ), instead of Wₕ(r ⊙ h). These are not generally interchangeable for matrices. Match the implementation before copying weights or counting biases.

With one bias per affine transform, a GRU has P = 3H(d + H + 1), versus 4H(d + H + 1) for this LSTM. At equal H it has 25% fewer recurrent parameters. Frameworks with separate input and recurrent biases change this count. Fewer parameters can reduce storage, but measured speed depends on kernels and hardware; accuracy depends on the task and training.

03 / EXPLANATION & ANALOGY

A bidirectional RNN runs two recurrent networks over the same input: one left to right, one right to left. They have separate learned parameters. At a position, concatenate the two states and let a task head use both contexts. Either direction can use a vanilla RNN, LSTM or GRU cell.

Two readers annotate a completed paragraph from opposite ends, then compare notes at the same word. Their meeting point is a token position, not whichever token each happened to process second.

This is useful for tagging a complete sentence, offline speech transcription or encoding a known source sentence for translation. A live predictor cannot use an unseen suffix. A backward pass is a second forward computation over reversed input, not backpropagation.

04 / GIVE THE IDEA A RULE
h→ₜ = F→(xₜ, h→ₜ₋₁)   ·   h←ₜ = F←(xₜ, h←ₜ₊₁)
uₜ = [h→ₜ ; h←ₜ] ∈ ℝ²ᴴ   →   head(uₜ)

The right-to-left state at t depends on positions t through T. The forward state depends on 1 through t. Concatenation keeps both vectors; it does not add them. The boundary states h→₀ and h←T₊₁ are initialized before their respective passes.

Go deeper · Alignment, latency & honest evaluation

For tokens [A, B, C], the backward computation visits C, then B, then A. Store or reorder its results by original token index before pairing forward and backward states. For token B, use [h→₂ ; h←₂], not [h→₂ ; h←₃].

At hidden width H = 4 per direction, each concatenated token representation has 8 features. A full-sequence summary can concatenate h→T with h←₁. Using the backward output aligned to the final token alone does not summarize the whole sequence in that direction. A bidirectional LSTM has 2 × 4H(d + H + 1) recurrent parameters under our bias convention; the head also gets a wider input.

Bidirectionality requires the chosen input window to be available. Offline transcription may use the whole recording; streaming can use a limited look-ahead window at a latency cost. Forecasting may bidirectionally encode a fully observed history window, but must never include the future being forecast. In translation, the whole source can be known while target generation remains causal.

Split related people, recordings or documents by source when appropriate; for forecasting use chronological evaluation and prevent overlapping future targets from leaking. Fit scalers on training data only. Padding is not meaningful time: mask padded outputs in the loss and prevent padded steps from contaminating state (for example, use lengths/packed sequences). Reset states between unrelated sequences. Carry state only when continuity and boundaries are intentional.

Design challenge · two products, one team

A. Tag faults in a completed machine recording. B. Raise a fault alert immediately as sensor readings arrive. Both may need clues from far earlier.

Discuss a defensible design

A bidirectional LSTM or GRU is a reasonable candidate for A because the recording is complete. For B, begin with a unidirectional gated model over observed readings; look-ahead would require an explicit delay. Compare LSTM and GRU on held-out machines or recordings with matched data, tuning budget and measured latency. Use chronological evaluation where the use case predicts future operation, fit preprocessing on training data, and prevent related windows from leaking. Neither cell is guaranteed to win.
