01
ENCODER–DECODER ARCHITECTURE

Read first. Then write.

01 / THE HOOK

Three English words become two French tokens. Which output belongs to which input clock?

START HEREI → love → you
THE TENSIONje → t’aime → EOS
03 / EXPLANATION & ANALOGY

A sequence is an ordered collection: words, audio frames, sensor measurements or video frames. Order matters: “dog bites person” and “person bites dog” contain the same words but tell different stories. A token ID is mapped to an embedding vector; its integer ID is not a meaningful numerical magnitude.

A recurrent encoder reads x₁ … xₙ, updating a hidden state hᵢ with the same learned rule at each position. The state is a changing summary; the weights are the learned rule. A separate decoder writes y₁ … yₘ, one target token at a time. This handles unequal lengths and output reordering. Encoding and decoding have separate parameter sets.

Imagine a reader writing a briefing note, then handing it to a translator. The reader’s clock counts source positions; the translator’s clock counts output positions. They do not have to tick together.

In the baseline below, the final encoder state c initializes the decoder through a learned bridge. At inference, the decoder starts with BOS, feeds its own last prediction back, and stops on EOS or a length limit. During training, teacher forcing instead supplies the correct previous target.

04 / GIVE THE IDEA A RULE
hᵢ = Encoder(hᵢ₋₁, Eₓ(xᵢ)); c = hₙ
s₀ = bridge(c); sₜ = Decoder(sₜ₋₁, Eᵧ(yₜ₋₁))
p(yₜ | y<ₜ, x) = softmax(Wo sₜ + bo)

i indexes source positions; t indexes target positions. E maps a token to a vector. h and s are encoder and decoder states. This baseline conditions on c through s₀; other baselines also inject c at each decoder step.

Go deeper · Start here if RNNs, dimensions or training are new

A simple recurrent cell is hᵢ = tanh(Wₓxᵢ + Wₕhᵢ₋₁ + b). For input width d and hidden width H, Wₓ is H × d, Wₕ is H × H and b is H × 1. Tanh acts coordinate by coordinate. A sequence of 4 inputs or 40 inputs still produces H coordinates per state. Practical encoders often use LSTM/GRU cells, but attention does not require knowing their gates.

For encoder width Hₑ and decoder width H𝒹, a bridge can be s₀ = tanh(Wbridge c + bbridge), with Wbridge of shape H𝒹 × Hₑ. An LSTM has a cell state too; a bridge must initialize all required recurrent states.

Teacher forcing shifts the target; the answer never becomes its own input.

The model’s probability for a whole output is ∏ₜ p(yₜ | y<ₜ, x). Training minimizes the sum of negative log probabilities of correct targets, excluding padded target positions. Teacher forcing makes training easier but creates a mismatch: inference must cope with its own mistakes. Greedy decoding takes the highest probability token each step; beam search keeps several partial outputs. Neither guarantees the best translation.

02
CONTEXT VECTOR BOTTLENECK

A whole sentence.
One fixed briefing note.

01 / THE HOOK

The translator may need the first name much later. What if every detail has to travel through one final summary?

START HEREA short sentence → c ∈ ℝᴴ
THE TENSIONA long sentence → c ∈ ℝᴴ
03 / EXPLANATION & ANALOGY

The baseline asks one fixed-width vector to preserve whatever every future output might need. As source sequences become more complex, that is a demanding representation and optimization problem. Useful details may become hard to recover, and a late training error must influence early recurrent computations through a long path.

A briefing note is convenient, but a translator may want to reopen the original notebook to check a name. Making the note larger can help; giving the translator access to all the notes changes the information route.

The experiment compares two sequences differing only in their first scalar input. Repeated updates can make their final summaries similar. This is an illustration of sensitivity loss, not a measured accuracy curve and not a claim that an H-dimensional state stores exactly H words.

The way out is to keep the encoder’s intermediate states H = [h₁, …, hₙ]. For each target step, retrieve a new context cₜ from this bank. The retrieved vector still has fixed width, but it no longer has to be the same summary for every output.

04 / GIVE THE IDEA A RULE
Baseline: c = hₙ for the whole output
Attention: cₜ = Σᵢ αₜᵢ hᵢ; Σᵢ αₜᵢ = 1
Toy experiment: hᵢ = tanh(xᵢ + r hᵢ₋₁)

The toy starts from h₀ = 0. Compare x₁ = +1 versus −1; all later inputs are zero. r is a scalar retention coefficient. The real architecture uses vectors and learned recurrent matrices.

Go deeper · Capacity, gradient paths and the cost of keeping notes

A real-valued vector has no literal fixed “word count.” Finite precision, learned features, data and optimization all affect which distinctions survive. A wider state or a gated recurrence can help; attention provides an additional route rather than proving those alternatives useless.

For this scalar recurrence, ∂hₙ/∂h₁ = ∏ᵢ₌₂ⁿ r(1 − hᵢ²). With |r| < 1, this product can shrink rapidly. Vector RNNs involve products of Jacobian matrices, which can shrink or grow. This is related to training gradients, but the plotted final-state difference is not itself a gradient measurement.

A source bank stores n × Hₑ numbers instead of just Hₑ. Global encoder–decoder attention compares all n source positions for each of m target steps, giving n × m score evaluations. Projection and recurrent computation add their own costs. Attention improves access to source states; it does not guarantee exact copying, perfect long-range memory or correct translation.

03
THE SHARED ATTENTION RECIPE

Which note matters
for this word?

01 / THE HOOK

When writing “je”, should the translator look at the same source evidence as when writing “t’aime”?

START HEREOne fixed context c
THE TENSIONA fresh context c₁, c₂, …
03 / EXPLANATION & ANALOGY

Attention is a differentiable retrieval operation. First, compare the decoder query with every source state to produce scores eₜᵢ. Second, apply softmax across source positions to obtain weights αₜᵢ. Third, multiply each entire source vector by its scalar weight and add the vectors to obtain context cₜ.

A spotlight can illuminate several notes at once. The brightnesses add to one, and the reader combines the illuminated information. A moving spotlight is not a command to copy exactly one note.

The three source vectors below are deliberately hand-chosen: h₁ = [1, 0], h₂ = [0, 1], h₃ = [1, 1]. With q = [1, 0] and dot scoring, scores are [1, 0, 1], weights are approximately [0.422, 0.155, 0.422], and c ≈ [0.845, 0.578]. The decoder still needs a vocabulary head to predict the next token.

04 / GIVE THE IDEA A RULE
eₜᵢ = score(qₜ, hᵢ)
αₜᵢ = exp(eₜᵢ) / Σⱼ exp(eₜⱼ)
cₜ = Σᵢ αₜᵢ hᵢ

For n source positions, eₜ and αₜ each contain n scalars. If hᵢ has Hₑ coordinates, cₜ also has Hₑ coordinates. The weights are source-position probabilities, not vocabulary probabilities.

Go deeper · Worked arithmetic, padding and reading a heatmap

exp([1, 0, 1]) = [2.718, 1, 2.718]; the denominator is 6.437. The first context coordinate is 0.422 × 1 + 0.155 × 0 + 0.422 × 1 ≈ 0.845. The second is 0.422 × 0 + 0.155 × 1 + 0.422 × 1 ≈ 0.578. Displayed values are rounded; calculations use full precision.

Stable softmax subtracts the largest valid score before exponentiating. Adding the same constant to every score leaves the weights unchanged. All equal scores give a uniform distribution. Padding is masked before normalization (conceptually score = −∞), giving zero weight; otherwise a fake position can steal probability mass. At least one source position must be valid.

The temperature slider uses softmax(e/T). Lower T sharpens existing preferences; it cannot choose between an exact tie. T = 1 is the classical formula used here. This is an experimental control, not a necessary part of Bahdanau or Luong attention.

Read a heatmap across one row: a single target step distributes a total of one unit over source positions. Columns need not sum to one. Alignments may be diffuse, reordered, repeated or many-to-one. Bright cells can be useful diagnostics, but attention weights alone are not proof of a linguistic alignment or a causal explanation.

BAHDANAU / ADDITIVE ATTENTION

Learn a small network
that compares two states.

01 / THE HOOK

The encoder writes 4 numbers per position. The decoder asks with 3. How can we compare vectors with different widths?

START HEREDecoder q ∈ ℝ³
THE TENSIONSource hᵢ ∈ ℝ⁴
03 / EXPLANATION & ANALOGY

Bahdanau attention learns a small feedforward scoring network. It separately projects the previous decoder state and each encoder annotation, adds the results, applies tanh, then combines the coordinates with a learned vector v. “Additive” names the addition inside this scoring function; it does not mean adding raw words or adding unnormalized probabilities.

Two specialists submit reports in different formats. A learned rubric converts both reports into comparable criteria, then combines the criteria into one relevance score.

In the familiar Bahdanau ordering, sₜ₋₁ queries the source before the new decoder state sₜ is formed. The context then helps the decoder update and predict. The original model uses a bidirectional encoder, so each source annotation includes information from both directions. Our two-coordinate bank keeps arithmetic visible.

04 / GIVE THE IDEA A RULE
eₜᵢ = vᵀ tanh(Wq sₜ₋₁ + Wh hᵢ + b)
αₜ = softmax(eₜ); cₜ = Σᵢ αₜᵢ hᵢ
sₜ = Decoder(sₜ₋₁, Eᵧ(yₜ₋₁), cₜ)

Wq: A × H𝒹; Wh: A × Hₑ; b and v: A × 1. A is the attention-network width. The context uses original hᵢ, so its width is Hₑ, not A. A vocabulary head reads the resulting decoder information.

Go deeper · A full scored pair, parameter shapes and the original model

For the interactive toy, Wq = Wh = [[1,0],[0,1]], b = [0,0], v = [1,−1], q = [1,0]. For h₁ = [1,0], the sum is [2,0], tanh gives [0.964,0], and e₁ = 0.964. For h₂ = [0,1], e₂ = tanh(1) − tanh(1) = 0. For h₃ = [1,1], e₃ = tanh(2) − tanh(1) ≈ 0.202. Softmax then produces the weights; a tanh output or a raw score alone is not a weight.

With H𝒹 = 3, Hₑ = 4, A = 5: Wq has 15 parameters, Wh has 20, v has 5, and optional b has 5, for 45 scoring parameters with this bias convention. The original paper writes its alignment function without the explicit bias shown in this common equivalent teaching form.

All scorer parameters learn through the translation loss; the standard soft attention mechanism does not require a separate hand-labelled alignment target. The original decoder has a richer recurrent/output construction than this high-level schematic. Source annotations may concatenate forward and backward hidden states, doubling the annotation width if each direction has the same width.

LUONG / MULTIPLICATIVE ATTENTION

Keep the retrieval recipe.

01 / THE HOOK

Do we need a little nonlinear network for every pair—or can multiplication give us a useful compatibility score?

START HEREAdd → tanh → v
THE TENSIONMultiply → sum
03 / EXPLANATION & ANALOGY

Luong attention offers several scoring functions. The dot form takes sₜᵀhᵢ; it has no scoring parameters and requires matching widths. The general form takes sₜᵀWa hᵢ; its learned matrix can map source width to decoder width. These are the multiplicative forms explored here. The paper also describes a concat scorer.

A dot product scores agreement between coordinates. A learned matrix changes the measuring instrument first: it can amplify, mix or reverse which source features matter to the query.

After computing scores, the same softmax and weighted sum retrieve cₜ. Luong combines cₜ with the current state sₜ to form an attentional state, which feeds the vocabulary head. Input feeding can also pass the previous attentional state into the next decoder step.

Both attention families let a decoder query an encoder memory bank. Score functions and decoder update order are useful distinctions; “additive” versus “multiplicative” alone does not dictate every architectural choice in later implementations.

04 / GIVE THE IDEA A RULE
Dot: eₜᵢ = sₜᵀhᵢ
General: eₜᵢ = sₜᵀWa hᵢ
cₜ = Σᵢ softmax(eₜ)ᵢ hᵢ
s̃ₜ = tanh(Wc [cₜ; sₜ]); p(yₜ) = softmax(Wo s̃ₜ + bo)

For column vectors, Wa is H𝒹 × Hₑ. [cₜ; sₜ] means concatenation, not addition. This is classical unscaled scoring; the √d scaling used in Transformer attention is not inserted here.

Go deeper · Worked general score, ordering and computational tradeoffs

With q = [1,1] and Wa = [[1,0],[0,2]], the transformed sources are [1,0], [0,2], [1,2]; general scores are [1,2,3]. Dot scores for the same query are [1,1,2]. The larger second-coordinate multiplier changes the source ranking. At q = [1,0], both scorers happen to agree—one input cannot establish equivalence.

Dot scoring costs roughly O(H) per source/query pair. General scoring can precompute Wa hᵢ for the source bank. Additive scoring can likewise precompute Wh hᵢ, then adds and applies tanh per pair. Runtime depends on dimensions and implementation; neither family is universally better. Global attention uses all valid source positions. Luong also proposes local attention over a selected window; that is outside this experiment.

This is encoder–decoder attention: queries come from the target side and memory from the source side. Transformer cross-attention preserves that broad role distinction but changes projections, scaling and architecture. Transformer self-attention compares positions within one sequence. Those are the next chapter, not hidden prerequisites today.

Your design challenge

A system translates variable-length medical instructions. It sometimes drops an early negation. Propose an encoder–decoder with attention. Sketch the two clocks and label hᵢ, query, scores, weights, cₜ and vocabulary probabilities. Choose a scorer, give its matrix shapes, explain teacher forcing, and show how padding is excluded. Name one test you would run to check whether the omission actually improves.

Instructor discussion rubric

Look for separate source and target clocks; an encoder bank; one source-normalized weight row per output; a context of width Hₑ; an output head over vocabulary; shifted correct targets in training and predictions in inference; zero padding weights; dimensionally valid scoring. Attention offers access but does not guarantee preserving negation. Evaluate held-out negation cases and compare omission rates with a baseline; a pretty heatmap alone is insufficient. For actual medical use, accuracy and clinical validation would need a separate deployment process.
