Why add anything to the loss?

✓ complete

Say thisTraining loss is the quantity we can differentiate. Test loss is the quantity we care about. Regularisation is any extra preference that trades a little training fit for better test performance — without shrinking the architecture by hand.

Goodfellow, Bengio & Courville (ch. 7) define regularisation as strategies that reduce test error, possibly at the expense of training error. Bishop & Bishop (ch. 9) start from the polynomial we already know: add (λ/2) wᵀw to the error, then list the modern versions of that idea. Prince (UDL ch. 9) splits the same ground into explicit penalties on weights and implicit ones (the optimiser, the stopping time, the noise in SGD).

the regularised objectiveẼ(θ) = E(θ) + λ Ω(θ)

E is the data term (MSE, cross-entropy). Ω is a preference. λ ≥ 0 is a hyperparameter: the inner optimiser does not fit it by gradient descent on the training set. Tune it on a validation split. λ = 0 recovers ordinary training. Large λ (or small dropout p, or a tiny stopping time) is a smaller effective model — underfitting if you overdo it.

L2 · ridge · weight decay

Shrink every weight

✓ complete
🔒

Say thisL2 adds λ‖w‖₂² to the loss. Every coordinate is pulled toward zero; none typically hits exactly zero. The closed form is ridge. The SGD implementation is weight decay.

Bishop (PRML §3.1.4) writes the regularised least-squares error as Ẽ(w) = (1/2) Σn (yn − wᵀφn)² + (λ/2)‖w‖₂². Set the gradient to zero: the data term XᵀX w − Xᵀy is joined by λ w. Rearrange:

ridgeŵ = (XᵀX + λ I)⁻¹ Xᵀ y

You have added λ to every eigenvalue of XᵀX. Directions the data do not constrain (tiny eigenvalues) are the ones shrinkage hits hardest. That is also why ridge is a numerical regulariser: XᵀX + λI is invertible even when XᵀX is not. In the limit λ → 0⁺ among interpolators, ridge selects the minimum Euclidean-norm solution.

board calculation · ŷ = w x, two points (1,2) and (2,3)
  1. SSE(w) = (2 − w)² + (3 − 2w)² = 5w² − 16w + 13
  2. λ = 0: 10w − 16 = 0 ⇒ w = 1.6000, SSE = 0.2000
  3. λ = 1: Ẽ = SSE + λ w² ⇒ w = 8/(5+λ) = 1.3333
  4. Training SSE rose to 0.5556. |w| fell. A little bias, less variance.

Weight decay is the same penalty as an SGD update: w ← (1 − ηλ) w − η ∇E. For vanilla SGD this is L2. For Adam, fold λ into the loss and the adaptive denominator rescales the L2 gradient too — AdamW applies (1 − ηλ) after the adaptive step.

Geometry: the constraint ‖w‖₂² ≤ η is a disk. Loss ellipses centred at OLS first touch the disk at a generic angle, so both coordinates survive. Goodfellow fig. 7.1 is the gradient-balance picture: ∇E points out of the ellipses, λw points toward the origin, they cancel at ŵ.

L1 · lasso

Delete some of them

✓ complete
🔒

Complete the section immediately above.

Say thisReplace ‖w‖₂² by ‖w‖₁. The constraint region is a diamond with vertices on the axes. Expanding loss ellipses typically hit a vertex first, so one coordinate is exactly zero. That is sparsity. Ridge will not do this at any finite λ.

Bishop writes a family Ωq = Σ |wj|q and notes that q = 1 is special: still convex, but the region has corners. That is the lasso. Nondifferentiable at 0, so you work with subgradients or a proximal map. The subgradient of |w| at 0 is the interval [−1, 1]. The data gradient has to be larger than λ in absolute value before the weight will leave 0.

soft-thresholdingSλ(z) = sign(z) max(|z| − λ, 0)

Three cases. |z| > λ: move z toward 0 by λ. |z| ≤ λ: output 0. This is the exact minimiser of (1/2)(w − z)² + λ|w|, and the lasso update when features are orthogonal.

board calculation · five points, two features, decoy x₂
  1. XᵀX = [[15, 1], [1, 2]], Xᵀy = [29.4, 2.3]
  2. OLS: w = (1.9483, 0.1759), train MSE = 0.0032
  3. Lasso, SSE + λ‖w‖₁, λ = 2: w = (1.8933, 0.0000)
  4. Ridge at the same λ: (1.7209, 0.1448) — both smaller, neither zero

Training MSE got worse (0.0032 → 0.0285) and a feature vanished. Elastic net (L1 + L2) was invented to share credit between correlated features: lasso prefers a vertex that keeps only one.

dropout

Delete activations for a step

✓ complete
🔒
Section locked

Complete the section immediately above.

Say thisInstead of deleting a weight forever, delete a random hidden unit for one step. The stored weights still exist; they are ignored this minibatch. At test, use the full net. Inverted dropout puts the 1/p scale in training so test is a plain forward pass.

Srivastava et al. (2014); Goodfellow §7.12. For each step draw mi ~ Bernoulli(p). Units with mi = 0 contribute nothing and receive no gradient. Prince (UDL figs. 9.8–9.9): dropout breaks co-adaptation. A hidden unit cannot assume that a particular neighbour will be present, so it cannot rely on a fragile cancellation — a kink that needs two units in concert. Each unit has to be useful in many random subsets.

inverted dropouttrain: h̃ = (m ⊙ h) / p    test: h̃ = h

If you drop at train and then use the full net at test without scaling, every activation is systematically larger at test. The original paper multiplied leftover weights by p at test. Inverted dropout divides by p when a unit is kept, which is cheaper and less error-prone. Typical p: 0.8–0.9 on inputs, 0.5–0.8 on hidden. Dropout on the output is unusual. With batch norm, many conv nets drop dropout; transformers still drop in attention and residual branches. MC dropout (keep dropping at test, average many masks) is a cheap uncertainty estimate — not the default.

Say thisIf a hidden unit’s values wander from 0.01 to 50 as earlier layers train, the next layer chases a moving target. Batch norm standardises each channel over the current minibatch, then lets the net undo that with two learned numbers γ and β. At test, freeze running averages — a single image has no batch companions.

Ioffe & Szegedy (2015). Bishop & Bishop §7.4.2 treat it next to data normalisation: the same idea, applied to hidden variables that keep moving. Prince §11.4 puts it in the residual-net chapter, because BN is how very deep residual stacks stay trainable. m is the batch size, ε ≈ 10⁻⁵. One (γ, β) pair per channel. If the net wants the identity, it can set γ = √(σ²+ε) and β = μ — so BN does not force every layer to zero-mean unit-variance features; it only makes that the default around which learning happens.

forward passû = (u − μ_B) / √(σ_B² + ε),   y = γ û + β
board calculation · u = (1, 3, 5, 7), ε = 0, γ = 2, β = 1
  1. μ_B = 16/4 = 4
  2. σ_B² = (9+1+1+9)/4 = 5, √5 ≈ 2.2361
  3. û ≈ (−1.3416, −0.4472, +0.4472, +1.3416) — mean 0, variance 1
  4. y = 2 û + 1 ≈ (−1.6832, 0.1056, 1.8944, 3.6832) — mean β, variance γ²

Use the population variance (divide by N), matching the BN forward pass — not the unbiased N−1 estimator. Mean and variance are functions of the whole batch, so the gradient of yi depends on every uj.

Two stories for why BN helps. Ioffe & Szegedy: it reduces internal covariate shift. Santurkar et al. (2018): it smooths the loss, so gradient descent is better conditioned. Operationally you need neither story to implement the four lines. BN is also a regulariser in the Goodfellow sense: μ_B and σ_B² jump every step, so training is less able to memorise. Smaller batches → noisier BN. Very small batches are why LayerNorm won in transformers.

early stopping

Delete training time

✓ complete
🔒
Section locked

Say thisIf longer training drives training loss down, the last epoch is often the wrong one to ship. Validation typically falls, then rises. The rise is overfitting in time rather than in width. Save θ at the validation minimum.

Goodfellow §7.8; Bishop PRML §5.5.2; Prince fig. 9.6. Protocol: split off validation (never take its gradient). Record Lval every epoch. Keep a copy of the best θ. If Lval has not improved for P epochs (patience), stop and restore. Patience P is a hyperparameter. The checkpoint index is a hyperparameter: the split that chose it is a validation set — do not pick the checkpoint with the best test loss and then report that number.

checkpointθ̂ = θt* with t* = arg mint Lval(θt)

Bishop shows that for a linear net with quadratic error, early stopping is approximately ridge with λ related to 1/(training time). Gradient descent on a quadratic is slowest along the small-eigenvalue directions — the same directions ridge damps. Stopping before those directions finish is like leaving them shrunk. For deep nets the equivalence is looser; the method remains a cheap regulariser that composes with all the others.

Say thisRead the pair (L_train, L_val) first. High–high: capacity or optimisation — relax the regularisers. Low–high: regularise, stop earlier, or add data. Then pick the tool that matches the model class.

A usable default for a modern residual conv net: batch norm (or LayerNorm) on, weight decay of order 10⁻⁴, early stopping on a validation split, dropout only if you still overfit. A linear model on many correlated features: lasso or elastic net, not dropout. A transformer: LayerNorm, residual dropout, weight decay, early stopping. The architecture already is a regulariser (inductive bias of convolution, residual identity, attention). Penalties sit on top.

One-line map. L1 deletes weights. L2 shrinks weights. Dropout deletes activations at train. BN re-scales activations. Early stopping deletes training time.

Five ideas to keep

L2 / ridge
Shrinks every weight. ŵ = (XᵀX + λI)⁻¹ Xᵀy. Almost never exact zeros. Weight decay is the SGD form.
L1 / lasso
Diamond corners. Soft-thresholding. Sparse w at finite λ.
Dropout
Random subnetwork each step; inverted scale 1/p at train; full net at test.
Batch norm
Normalise over the minibatch, then γ û + β. Test uses running statistics.
Early stopping
Keep θ at the best validation epoch. Time is capacity.
The split
Tune λ, p, patience on validation. Report test once.
