## Deep learning worksheets

Public GitHub Pages site: **https://ashwin-tewary.github.io/dl-worksheets/**

- **[Generalisation](worksheet_generalisation.html)** — underfitting, overfitting, the bias–variance decomposition, and double descent.
- **[Regularisation · worked numbers](worksheet_regularisation.html)** — L1, L2 / weight decay, dropout, batch normalisation, and early stopping.
- **[Regularisation · lecture notes](lab_regularisation.html)** — theory, textbook figures, and live plots for delivering the lecture (same URL as before).

Click any dotted term’s **i** on the click-to-fill sheets for a definition, formula, and textbook pointer (Bishop PRML, Goodfellow et al., Bishop & Bishop 2023, Prince UDL). The **glossary** button lists every term.

Nothing is scored. Answers unlock in order. Print works.

Rebuild the HTML files after editing the sources:

```bash
python3 assemble.py
python3 assemble_lab.py
```
