# Deep Learning worksheets

Interactive sheets in the same spirit as [worksheet 07 on momentum](https://kartikgupta98.github.io/dl-worksheets/worksheet07_momentum_nag.html).

## Generalisation

**[Open the worksheet](worksheet_generalisation.html)** — underfitting, overfitting, the bias–variance decomposition, and double descent.

Click any dotted term’s **i** for a definition, formula, and textbook pointer (Bishop PRML, Goodfellow et al., Bishop & Bishop 2023, Prince UDL). The **glossary** button lists every term.

Nothing is scored. Answers unlock in order. Print works.

Rebuild the single HTML file after editing the `ws_part_*.js` sources:

```bash
python3 assemble.py
```
