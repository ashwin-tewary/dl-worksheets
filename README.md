## Deep learning worksheets

Public GitHub Pages site: **https://ashwin-tewary.github.io/dl-worksheets/**

- **[Generalisation](worksheet_generalisation.html)** — underfitting, overfitting, the bias–variance decomposition, and double descent.
- **[Regularisation](worksheet_regularisation.html)** — L1, L2 / weight decay, dropout, batch normalisation, and early stopping.

Click any dotted term’s **i** for a definition, formula, and textbook pointer (Bishop PRML, Goodfellow et al., Bishop & Bishop 2023, Prince UDL). The **glossary** button lists every term.

Nothing is scored. Answers unlock in order. Print works.

Rebuild the HTML files after editing the `ws_part_*.js` or `reg_part_*.js` sources:

```bash
python3 assemble.py
```
