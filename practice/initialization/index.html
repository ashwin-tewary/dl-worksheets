01
ZERO & CONSTANT INITIALIZATION

Different neurons.
The same story.

Complete ✓
IN ONE MINUTE

Identical hidden units cannot learn different features while their incoming weights, biases, and outgoing connections remain symmetric. Randomness gives each neuron a different starting point.

∂L / ∂Wij = δi hj Equal δ across units → equal row updates

TRY THIS

At the board Why identical rows stay identical

For h = φ(Wx + b), identical rows of W and equal biases give identical preactivations. If the downstream connections are also symmetric, backpropagation gives the same δi for every hidden unit.

∂L / ∂Wij = δixj   →   Wi: = Wk: after every update

The update is identical across rows, not necessarily across columns: different xj can produce different column gradients. Equal incoming weights alone do not guarantee equal gradients if outgoing weights differ. Zero biases are fine when random weights have already broken symmetry.

Worked example. x = [1, 2] and δ = [0.5, 0.5, 0.5] produce three identical gradient rows [0.5, 1.0]. This specified δ need not arise from an entirely zero-initialized deep network.

02
NAIVE RANDOM INITIALIZATION

Random is a start.
Scale is the difference.

Complete ✓
IN ONE MINUTE

Random weights break symmetry. Their scale decides whether a signal grows or fades. In a linear network, even a small mismatch compounds with depth. With tanh, large inputs cause saturation; the activations themselves stay bounded.

qℓ = nin σ² qℓ−1Linear activation · q = E[a²] · independent, zero-mean weights

TRY THIS

At width 64, compare σ = 1 with σ ≈ 0.125. Then switch to tanh.

At the board Why fan-in multiplies the variance

Write z = Σwjaj. Under independent zero-mean weights, independent input coordinates, and weights independent of inputs, cross terms vanish. Then E[z²] = nin Var(w) E[a²]. For centered inputs, E[a²] = Var(a).

n = 64, σ = 1, Var(x) = 1   ⇒   Var(z) = 64

For repeated equal-width linear layers, qL = (nσ²)L. For tanh, this linear recurrence no longer holds after the activation: q is bounded by 1, while tanh′(z) = 1 − tanh²(z) shrinks in saturated regions. Large weights and many layers make gradient behavior more subtle than activation variance alone.

03
XAVIER / GLOROT INITIALIZATION

Give the signal
room to travel.

Complete ✓
IN ONE MINUTE

Xavier balances the competing forward and backward scaling requirements. With equal widths and linear activations, it preserves the expected signal energy. For tanh, it is a useful starting point, not a promise of constant variance at every depth.

Var(w) = 2 / (nin + nout)Normal: σ = √Var(w) · Uniform: bounds ±√(6 / (nin + nout))

At the board A compromise between two directions

Forward preservation asks for nin Var(w) ≈ 1. Backward preservation asks for nout Var(w) ≈ 1, assuming derivatives near one and independent gradients. These conditions coincide when widths match. Xavier uses 2/(nin + nout) as a compromise.

nin = 256, nout = 512   ⇒   σ = √(2/768) ≈ 0.0510

A uniform variable on [−b, b] has variance b²/3. Setting b = √(6/(nin + nout)) gives the same target variance. The explorer uses gain 1. Tanh-specific gain conventions change the scale, and sigmoid has a nonzero mean that can complicate deep signal propagation.

04
HE / KAIMING INITIALIZATION

Half the gate.
Twice the variance.

Complete ✓
IN ONE MINUTE

For symmetric preactivations, ReLU removes half the second moment, E[z²]. He initialization compensates with twice the weight variance. Signal energy can then remain steady through an equal-width ReLU network.

Var(w) = 2 / ninLeaky ReLU with slope α: Var(w) = 2 / ((1 + α²)nin)

YOUR EXPERIMENT

LOOK CLOSELY

The curves show q = E[a²]. ReLU outputs have a positive mean, so their variance is smaller than q.

At the board Second moment is not variance

For a centered symmetric distribution, E[ReLU(z)²] = ½E[z²]. But ReLU(z) has a positive mean. If z ∼ N(0, v), then:

E[a] = √(v / 2π)
E[a²] = v / 2
Var(a) = v(½ − 1/2π)

With qin = 1 and He weights, v = 2. The output second moment is 1 while its variance is approximately 0.682. It is incorrect to say ReLU simply halves the centered variance.

Leaky ReLU gives E[a²] = (1 + α²)E[z²]/2, yielding the adjusted He variance. This derivation is specific to rectifiers; GELU and SiLU do not exactly satisfy the same rule.

Worked example. With nin = nout = 100, Xavier variance is 0.01 and He variance is 0.02. The ratio He/Xavier is 2.

Transfer it to a real model What to measure next

Start by checking activation means, second moments, saturation rates, and gradient norms layer by layer. For convolutional layers, fan-in includes input channels × kernel height × kernel width. Residual connections, normalization, layer shapes, and activation-specific gains can change the picture.

Small gradients are evidence, not a unique diagnosis. The case above deliberately isolates an initialization mismatch; learning rate, architecture and data can also cause stalled training.

# PyTorch · W shaped [fan_out, fan_in]
torch.nn.init.xavier_normal_(linear.weight, gain=1.0)
torch.nn.init.kaiming_normal_(relu_layer.weight,
                             mode="fan_in", nonlinearity="relu")
torch.nn.init.zeros_(relu_layer.bias)
